# Privacy

Drinkwaterpunten for Karoo does not collect, store, sell, or share personal data.

1. The extension reads the current position and active route from Karoo OS only to choose which water points to draw. This data stays on the Karoo.
2. A manual sync queries public OpenStreetMap data through the Overpass API. The request contains no position or route data.
3. The app has no account, analytics, ads, crash reporter, or tracking code.
4. The app stores only the downloaded water-point file and its update time in private app storage.

Questions can be raised through the repository issue tracker.
