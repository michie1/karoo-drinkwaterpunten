# Hammerhead Extension Library listing

## Name

Drinkwaterpunten

## Short description

Public drinking-water points on the Karoo ride map, ready for offline rides.

## Description

Drinkwaterpunten adds a switchable water-point layer to the native Karoo map. It ships with an offline snapshot and can fetch fresh public points by hand. The layer shows useful points near the rider and active route while keeping the load low on Karoo 2.

## Main features

1. Native switchable Karoo map layer.
2. Offline public water-point data for the Netherlands.
3. Manual updates from Drinkwaterpunten.nl.
4. Native pin details and navigation flow.
5. No account, ads, analytics, or tracking.

## Compatibility

Karoo 2 and the current Karoo on Karoo OS 1.538.2049 or newer.
