# Changelog

## 1.0.0

1. Show public drinking-water points as a native Karoo map layer.
2. Include an offline snapshot and a manual GPX sync.
3. Show points within 30 km of the rider and within 5 km of an active route.
4. Limit the layer to 250 points, with nearby points first.
5. Open native Karoo pin details when a point is tapped.
6. Add source credit for Drinkwaterpunten.nl and OpenStreetMap.
