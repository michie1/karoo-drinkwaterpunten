# Contributing

1. Open an issue before a large change.
2. Keep the app usable offline and light enough for Karoo 2.
3. Add or update unit tests for changed data or map rules.
4. Run `./gradlew test assembleDebug` before opening a pull request.
5. Do not add signing keys, tokens, APKs, or local SDK paths to Git.
6. Report missing or wrong water points through OpenStreetMap, not as hard-coded app changes.
