# Data sources and licence

1. Water-point data is downloaded from [drinkwaterpunten.nl](https://drinkwaterpunten.nl/gpx).
2. Drinkwaterpunten.nl states that its points are based on contributions to [OpenStreetMap](https://www.openstreetmap.org/copyright).
3. OpenStreetMap data is available under the Open Database Licence. The bundled and synced point database remains subject to that licence and its attribution rules.
4. The app source code is separate from the point database and is available under the MIT Licence.
5. Corrections should be made in OpenStreetMap so they can flow back into the public feed.
